# A5-PI2-backend

## Pre-requisites : 
- Docker running
- Npm software
- .env file 

## How to start for the first time for *LINUX* - be on develop branch
> npm run iniate

> npm start

## How to start for the first time for *WINDOWS* - be on develop branch
> npm run initiate-windows 

> npm run start-windows

## For other times 
for linux :
> npm start

for windows :
> npm run start-windows
